# 발표용 샘플 이미지 폴더

이 폴더에 대표 이미지 3~5장(png/jpg)을 넣으면 판정 데모 탭에 클릭용 썸네일 버튼이 자동으로 생깁니다.
파일 업로드 없이 버튼 한 번으로 바로 시연할 수 있습니다.

권장 구성(각 상황을 하나씩):
- 무결함이 명확한 이미지 1장
- 균열(D1)이 명확한 이미지 1장
- 미용착(D4)이 명확한 이미지 1장
- 애매/경계 구간(사람확인으로 갈 만한) 이미지 1~2장

파일명이 버튼 라벨로 그대로 표시되니 알아보기 쉬운 이름으로 저장하세요.
(예: `무결함_예시.png`, `균열_예시.png`, `애매_경계1.png`)
